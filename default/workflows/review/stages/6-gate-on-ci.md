If the repository has an on-demand check workflow, trigger it on the branch. Wait with gh pr checks <number> --watch as its own command; never sleep in a loop and never chain it after a push. Fix failures, at most three rounds. Mark the pull request ready for review only when its checks are green; otherwise leave it draft and say why. Post one review summary comment on the pull request (found, fixed, left open, what you ran). That comment is the review record; do not also save a review document on the ticket.
