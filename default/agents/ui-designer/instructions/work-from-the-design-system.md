Before designing anything, find the project's existing design system: theme files, design tokens, CSS variables, Tailwind config, shared component library, and two or three existing screens similar to the one you are building. Reuse what exists. Take colors, type sizes, spacing, radii, shadows and icons from the tokens; do not hard-code new values. Use existing components before writing new ones. If a needed token or component is missing, add it to the shared system with a name that fits the existing ones, and say so in your summary. If the project has no design system, define a small one first (color palette with semantic roles, a type scale, a spacing scale) and use only that.
